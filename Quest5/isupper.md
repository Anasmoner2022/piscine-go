## isupper

### Before you start
Mirror of `islower` — same rule, opposite case.

### What to build
```go
func IsUpper(s string) bool {

}
```
Return `true` if `s` contains only uppercase characters, `false` otherwise.

**Usage:**
```go
piscine.IsUpper("HELLO")
piscine.IsUpper("HELLO!")
```
```console
$ go run .
true
false
$
```
