## printdigits

### What to build
Print the decimal digits `0` to `9`, in order, on a single line.

**Usage:**
```console
$ go run .
0123456789
$
```

### Watch for
Same shape as `printalphabet`, different characters. If you already solved that one, this should take you seconds — notice what actually changed (the range of characters) versus what stayed the same (how you print each one).

### Stuck? Ask better
If this one's giving you trouble but `printalphabet` worked, compare the two side by side and say exactly what's different — the bug is almost always in that difference.
