## printalphabet

### What to build
Write a program that prints the lowercase Latin alphabet, `a` to `z`, on a single line.

**Usage:**
```console
$ go run .
abcdefghijklmnopqrstuvwxyz
$
```

### Watch for
"On a single line" means no line break between letters — only at the very end, if any. This is your first z01 exercise: figure out how `z01.PrintRune` differs from `fmt.Println` — specifically, what it prints and what it doesn't add for you.

### Stuck? Ask better
Show the code that prints each letter and its actual output. If letters are missing or extra, say which end (start or finish) is off — that points to your range, not your printing.
