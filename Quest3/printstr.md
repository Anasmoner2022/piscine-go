## printstr

### What to build
```go
func PrintStr(s string) {

}
```
Print the characters of `s`, one at a time.

**Usage:**
```go
piscine.PrintStr("Hello World!")
```
```console
$ go run . | cat -e
Hello World!
```

### Watch for
"One at a time" is the point of this exercise — how do you access individual characters of a Go string, and what type do you get back when you do?

### Stuck? Ask better
Show how you're accessing each character and what actually printed. If you're getting numbers instead of letters, that tells you what type you're printing without converting it.
