## semantic-page

### Before you start
This exercise isn't about making anything look good — it's about structure. When you later prompt an AI to build a page, you need to be able to look at what it generates and tell whether the structure makes sense, not just whether it "looks right" in the browser.

### What to build
Create `index.html` with this structure:
- A `<header>` containing an `<h1>` with the text `Hotel Piscine`
- A `<nav>` inside the header with at least one `<a>` link
- A `<main>` element (this is where page content will go)
- A `<footer>` containing some text

### Watch for
`<div>` can visually produce the same layout as `<header>`/`<main>`/`<footer>` — but semantic tags carry meaning a `<div>` doesn't. The grader checks for the actual tags, not just visual structure.

### Stuck? Ask better
Say which required element the grader says is missing or misplaced, and paste the relevant chunk of your HTML — not the whole file.
