## css-layout

### What to build
Given HTML with several `.room-card` elements inside a `.room-list` container, write CSS so `.room-list`:
- arranges its children in a row (not stacked vertically)
- wraps to a new line when there isn't enough horizontal space
- has consistent spacing between cards (not just on the outer edges)

### Watch for
There's more than one CSS approach that satisfies these three requirements — the grader checks the *resulting layout behavior*, not which property names you used to get there.

### Stuck? Ask better
Say which requirement is failing: not arranging as a row, not wrapping, or inconsistent spacing — those point at different properties (direction vs. wrapping vs. gap).
