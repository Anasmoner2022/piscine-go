## now-get-to-work

"Something terrible happened"

### What to build
Clone [github.com/01-edu/the-final-cl-test](https://github.com/01-edu/the-final-cl-test). Submit your solution in `my_answer.sh`, which should print the answer to whatever that repo is asking when executed.

**Usage:**
```console
$ bash my_answer.sh | cat -e
John Doe$
$
```

### Watch for
This is Quest 1's capstone — it's meant to combine tools from earlier `cl-camp` exercises rather than teach something new. If you're stuck, ask yourself which earlier exercise this most resembles before reaching for a new command.

### Stuck? Ask better
Say what the cloned repo is actually asking for, what output you're getting, and which combination of commands you've already tried. This is the exercise where a vague "I don't know where to start" is least useful — you have 12 exercises' worth of tools behind you, so name which ones you've ruled out.

### Hint
You could combine `head` and `tail`.
